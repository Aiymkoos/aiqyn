# Aiqyn — персональный маршрут поступления

**LOCUS Startup Hackathon 2026 · кейс 02 «Персональный маршрут поступления» · код `LOCUSCASE2`**

Живой сайт: **https://aiymkoos.github.io/aiqyn/** — открывается без регистрации и оплаты, с телефона.

«Айқын» по-казахски — «ясный». Сервис ведёт абитуриента от шести вопросов до персонального плана
и на каждом шаге показывает, **почему** результат именно такой. Мы не выбираем за человека —
мы показываем устройство выбора.

---

## 1. Задача

Абитуриенту не хватает не информации, а **основания выбрать**. Списков вузов в интернете полно,
но непонятно, что подходит именно ему, что мешает, и что делать прямо сейчас. Кейс требует
связный путь из семи этапов, объяснимые рекомендации, реакцию на изменение ответов, мобильную
версию и честные данные с источниками.

## 2. Решение

Метафора — **аэропорт**. Профиль абитуриента — посадочный талон, который заполняется по мере
ответов и всегда висит сверху (так человек всегда знает, где он и что уже сделал). Вузы —
рейсы на табло: **ПОДХОДИТ / БЛИЗКО / НЕТ ДАННЫХ / НЕ ПРОХОДИТ**. Поменял ответ — табло
перещёлкивается, а баннер «Маршрут перестроен» объясняет, кто и почему выпал или поднялся.

Семь этапов кейса — семь «станций» маршрута:

| # | Экран | Что получает пользователь |
|---|---|---|
| 1 | Вход | что это и что будет на выходе; живой пример табло |
| 2 | Профиль | 6 вопросов: направления, балл ЕНТ (можно «пока не знаю»), бюджет или «только грант», языки, города и готовность к переезду, общежитие + что важнее всего |
| 3 | Диагностика | цель, сильные стороны, ограничения, чего не хватает в данных, воронка отбора |
| 4 | Вузы | «взлётная полоса» по баллу + талоны вузов; у каждого — из чего собран балл, какие фильтры прошёл, где источник каждой цифры; **пульт** для мгновенного изменения ответов; развилки «что если» |
| 5 | Сравнение | два вуза по тем параметрам, которые пользователь отметил важными |
| 6 | План | шаги с датами и происхождением дат, отметки выполнения, экспорт в календарь телефона (.ics), ссылка для родителей |
| 7 | Ближайший шаг | одно выделенное действие, прогресс, «сделано» |

Состояния: загрузка (табло «прогревается»), пусто (ничего не подошло → развилки), ошибка
(с восстановлением), **не хватает данных** (заштрихованный статус вместо выдуманного балла),
профиль заполнен не до конца (возврат к нужному вопросу).

### Что мы добавили от себя

- **Шансы на грант с объяснением** — балл сравнивается с прошлогодним проходным *в этом вузе по этой группе программ*, всегда с пометкой «ориентир, не гарантия».
- **Развилки «что если»** — какое одно изменение (балл, бюджет, город, язык) открыло бы больше вузов.
- **План в календарь телефона** одной кнопкой и **ссылка для родителей** — адрес страницы содержит профиль, открывается без регистрации.
- **Честность как функция** — страница «Источники», чипы «проверено / демо / нет данных» у каждой цифры, достоверность подбора в процентах.

## 3. Стек и архитектура

Чистые **HTML + CSS + JavaScript (ES-модули)**, без фреймворков и сборщика. Деплой — GitHub Pages
из ветки `main`. Никаких ключей, серверов и внешних API в рантайме: сайт работает офлайн после загрузки.

```
index.html              оболочка: посадочный талон, экран, шторка, баннер
css/                    tokens (палитра, шрифты) · base · components · screens
js/app.js               hash-роутер, контекст данных, защита экранов результатов
js/state.js             профиль в localStorage, кодирование профиля в ссылку
js/engine/
  facts.js              fact / demo / unknown — происхождение каждого значения
  score.js              детерминированный подбор: жёсткие фильтры + весовые слагаемые
  delta.js              дельта между прогонами («маршрут перестроен»), развилки «что если»
  roadmap.js            план шагов с датами и их происхождением
  format.js             тенге, склонения
js/ui/                  талон, табло (перещёлкивание, FLIP-перестановка), экраны, открытки
data/
  universities.js       22 вуза, 293 программы — СГЕНЕРИРОВАНО из tools/cache
  directions.js         10 направлений → группы образовательных программ (ГОП)
  calendar.js           даты кампании и пороги ЕНТ с источниками
tools/build-data.py     сборка data/universities.js из сырых данных
tools/cache/            сырые данные с univision.kz (json) — след каждой цифры
tests/engine.test.js    20 тестов движка (node:test)
```

### Движок подбора — не LLM

Ядро детерминированное: на один и тот же профиль всегда один и тот же ответ. Это принципиально —
жюри меняет ответы и смотрит на реакцию, и мы можем доказать, что список изменился именно из-за правки.

**Жёсткие фильтры** (проходит / не проходит / нельзя проверить, у отказа всегда причина и разрыв):
направления → язык обучения → порог ЕНТ вуза по группе программ → деньги (платно: бюджет против
стоимости; грант: балл против прошлогоднего проходного) → город.

**Мягкие слагаемые** (в сумме 100): направления 35, деньги/грант 20, город 15, запас по ЕНТ 15,
язык 10, общежитие 5. В знаменатель попадает только применимое: если общежитие не нужно, оно не
влияет на балл вообще. Разрыв ≤ 15 баллов ЕНТ или ≤ 25 % стоимости — статус «близко» с указанием,
чего не хватает.

**Неизвестное поле не отсеивает вуз и не начисляет баллов — оно снижает достоверность.** Если
неизвестны и балл, и бюджет, вуз получает статус «нет данных»: балл по одному полю хуже отсутствия
балла.

## 5. Запуск локально

Нужен любой статический сервер (ES-модули не грузятся с `file://`):

```bash
git clone https://github.com/Aiymkoos/aiqyn.git
cd aiqyn
python tools/serve.py 8080      # или: python -m http.server 8080
# открыть http://127.0.0.1:8080
```

Тесты движка (Node 20+):

```bash
npm test
```

## 6. Тестовый сценарий для жюри

1. Открыть сайт с телефона → «Построить мой маршрут».
2. Ответить: IT и программирование · ЕНТ 96 · платно до 1,8 млн ₸ · русский + английский · Алматы · общежитие нужно, важнее всего цена и шанс на грант.
3. Диагностика: посмотреть воронку (22 → … → 6 подходят).
4. Табло: нажать на любой талон — разбор балла по слагаемым, фильтры, грант «в 2025 сюда проходили с N», источники.
5. **Главный тест:** нажать «Пульт» → переключить «Только грант» или сдвинуть бюджет до 600 тыс. — талоны перещёлкиваются, баннер «Маршрут перестроен» называет, кто выпал и почему. Поменять город на Астану, добавить «готов переехать», сдвинуть ЕНТ до 70 — каждый раз результат меняется объяснимо.
6. Развилки: нажать «ЕНТ +15 → ещё N вузов» — профиль обновится, табло перестроится.
7. Сравнение двух вузов → План (отметить шаг, «В календарь», «Ссылка для родителей») → Ближайший шаг.
8. Состояния: выбрать только «Медицина» + «только грант» + «пока не знаю балл» → «нет данных» и пустой результат с развилками; открыть `#/board` в чистом браузере → «профиль заполнен не до конца».

## 8. AI и внешние сервисы

- **В рантайме LLM не используется.** Подбор, объяснения, дельта и развилки — детерминированный код (см. раздел 3). Это осознанный выбор: объяснимость, воспроизводимость и работа без сети.
- **При разработке** использовался AI-ассистент для написания кода (Claude Code, Anthropic) — как разрешено положением. Постановка задачи, продуктовые решения, проверка данных и дизайн-направление — команда.
- Внешних API нет. Шрифты — Google Fonts (Barlow Condensed, Manrope, JetBrains Mono).

## 9. Готовые компоненты

UI-киты и библиотеки не использовались. Всё, что на экране — собственная вёрстка. Иллюстрации
городов на карточках вузов **генеративные**: рисуются из id вуза (чужие фотографии кампусов брать
нельзя). Готовых заранее материалов до старта хакатона не было.

## 10. Техническая справка

- **Модели:** нет. **API:** нет. **Библиотеки:** нет (в рантайме); `node:test` для тестов, `pypdf`/Python только для сбора данных.
- **Данные:** 22 вуза Казахстана, 293 записи «направление × группа программ»; 778 значений со ссылкой на источник и датой проверки, 41 демонстрационное, 104 честных «нет данных».
- **Методы проверки:** 20 автотестов движка (детерминизм, причины отказов, «неизвестное не отсеивает», сценарий жюри «изменение бюджета меняет результат», восемь эталонных профилей); ручной прогон всех семи экранов на 390 px; сверка проходных баллов агрегатора с документом самого вуза для КазАТУ (7 групп программ — совпадение по всем).
- **Безопасность:** нет аккаунтов, нет серверов, нет ключей; профиль хранится только в браузере пользователя; ссылка «для родителей» содержит только ответы анкеты.

## 11. Известные ограничения

- Языки обучения и общежития — демонстрационные, не сверены с сайтами вузов (помечены в интерфейсе).
- Проходные баллы — по итогам конкурса 2025; конкурс 2027 будет другим. Сервис нигде не говорит «ты проходишь».
- Стоимость — минимальная по направлению; в конкретной программе может быть выше.
- Квоты (сельская, для сирот и др.) и вузы с собственными экзаменами (Назарбаев Университет) не учитываются.
- Даты 2027 года не опубликованы — показан ориентир по 2026 с пометкой.
