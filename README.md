# Aiqyn — персональный маршрут поступления

LOCUS Startup Hackathon 2026, кейс 02 «Персональный маршрут поступления».

Сервис ведёт абитуриента от короткой анкеты до персонального плана и на каждом
шаге показывает, **почему** результат именно такой. Мы не выбираем за
абитуриента — мы показываем устройство выбора.

Полное описание, стек и запуск появятся вместе с кодом.
