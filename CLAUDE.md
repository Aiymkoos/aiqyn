# Aiqyn — персональный маршрут поступления

LOCUS Startup Hackathon 2026, кейс 02. Код сабмита `LOCUSCASE2`.
**Дедлайн: 19 сентября 2026, 12:00 по Астане.** Финальная версия фиксируется в ветке `main`.
Полный бриф проекта: `docs/AIQYN-BRIEF.md` — читать первым.

## Позиция продукта
Мы не выбираем за абитуриента — показываем устройство выбора. Ядро подбора
детерминированное (не LLM): жёсткие фильтры + мягкие веса, балл собран из
именованных слагаемых, поэтому объясним; после правки ответа показываем дельту.

## Чек-лист кейса (обязательно)
7 этапов: вход → анкета → диагностика → рекомендации (≥3, с «почему») →
сравнение (≥2) → roadmap → ближайший шаг + отметка прогресса.
Состояния: загрузка, пусто, ошибка, не хватает данных, профиль заполнен не до конца.
Мобильный экран первым (390px, без горизонтальной прокрутки).
После изменения ключевого ответа рекомендации заметно и объяснимо меняются.

## Запрещено
Гарантии поступления и «ты проходишь на грант»; числа без источника (только
`fact(значение, ссылка, дата)` / `demo` / `unknown`); чужие фото кампусов;
ключи и пароли в репозитории; копирование дизайна LOCUS.
